## VPS Deploy Bot 🚀                                                                           

Simple docker build scripts for multiple Linux-based VPS containers.

## Supported OS Images

- Arch Linux

- Fedora

- Kali Linux

- Alpine Linux

- Debian

- Ubuntu


## Installation

- bash <(curl -fsSL https://github.com/NotFlexxy-1/discord-vps-deploy-bot/main/install.sh)
